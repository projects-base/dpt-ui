What is Daily Problem Dynamic Tracker?

Daily Problem Dynamic Tracker turns your daily coding practice into a record you can actually review. Solve a problem on LeetCode, HackerRank or CodeChef, and it captures the problem, rates your solution with Google Gemini, writes a formatted Google Doc into your own Drive, appends a row to your tracking Sheet, and updates the streak and analytics on this dashboard.

🧩

The Chrome extension

Daily Problem Dynamic Tracker — the browser extension. It reads the problem page you are on and the code you highlighted, then logs it in one click.
